# ชีวิตสุดท้าย

เกมเอาตัวรอดจากซอมบี้แบบข้อความและตัวเลือก สุ่มชีวิตคนในประเทศไทย พร้อมเหตุการณ์ กลุ่มผู้รอดชีวิต การเดินทาง และบทสรุปของแต่ละรอบ

## เล่นในเครื่อง

เปิด `index.html` ด้วยเบราว์เซอร์สมัยใหม่ เกมทำงานเป็นไฟล์เว็บแบบ static ไม่ต้องติดตั้งเซิร์ฟเวอร์

## เผยแพร่และอัปเดต

เว็บไซต์เผยแพร่ด้วย GitHub Pages และ workflow ใน `.github/workflows/deploy.yml` ทุกครั้งที่ push การเปลี่ยนแปลงไปยัง `main` ระบบจะนำไฟล์หน้าเว็บเวอร์ชันล่าสุดไปเผยแพร่อัตโนมัติ

1. แก้ `index.html` หรือไฟล์รูป/เสียงที่เกมใช้งาน
2. บันทึกการเปลี่ยนแปลงเป็น commit
3. push ไปยัง branch `main`
4. รอ GitHub Actions จบ แล้วเปิดเว็บไซต์เพื่อรับแพตช์ล่าสุด

สามารถดูประวัติการเปลี่ยนแปลงได้ใน [CHANGELOG.md](CHANGELOG.md)
